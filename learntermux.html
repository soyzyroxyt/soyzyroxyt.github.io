Comandos básicos de Linux/Termux

  • ls — lista archivos y carpetas
  • cd carpeta — entra a una carpeta
  • cd .. — sube un nivel
  • pwd — muestra la ruta actual
  • mkdir nombre — crea una carpeta
  • touch archivo — crea un archivo vacío
  • rm archivo — elimina un archivo
  • rm -r carpeta — elimina una carpeta y su contenido
  • clear — limpia la pantalla

Gestión de paquetes

pkg update && pkg upgrade
pkg install nombre
pkg uninstall nombre
pkg list-installed
pkg search palabra

Paquetes útiles: git, python, nodejs, php, openssh, apache2.

Acceso al almacenamiento del teléfono

termux-setup-storage

Pide permiso para acceder a tus archivos. Aparece una carpeta storage con accesos a Descargas, DCIM, Música, etc.

Atajos y trucos útiles

  • Ctrl+Alt+C — abre nueva sesión
  • Volumen abajo + tecla — teclas especiales (Esc, Tab, flechas)
  • history — comandos usados anteriormente
  • nano archivo — edita un archivo de texto
  • exit — cierra la sesión actual

Git y GitHub

pkg install git
git config --global user.name "TuNombre"
git config --global user.email "tu@correo.com"
git clone https://github.com/usuario/repo.git
git add .
git commit -m "mensaje"
git push origin main
git pull

Para subir cambios necesitas una cuenta en GitHub y, normalmente, un token de acceso personal en vez de contraseña.

Introducción a Nmap

Escaneo de redes para auditorías y administración. Úsalo solo en redes/equipos propios o con autorización explícita.

pkg install nmap
nmap 192.168.1.1
nmap -sV 192.168.1.1
nmap -p 1-1000 192.168.1.1
nmap 192.168.1.0/24

Practica en tu red doméstica o en laboratorios como TryHackMe o Hack The Box.

Introducción a OSINT

Recolección de información pública, usada en investigación, periodismo y ciberseguridad defensiva.

  • whois — registro de dominios
  • theHarvester — correos y subdominios públicos
  • Google Dorking — site:, filetype:, intitle:
  • Shodan — dispositivos conectados a internet
pkg install whois
whois ejemplo.com

Herramientas de red

  • tcpdump — captura tráfico de red
  • netstat / ss — conexiones activas y puertos
  • traceroute — ruta de paquetes hasta un destino
  • dig / nslookup — consultas DNS
  • curl / wget — peticiones HTTP
pkg install tcpdump net-tools traceroute dnsutils curl wget

Herramientas de análisis web

  • Nikto — escáner de vulnerabilidades básicas (requiere autorización)
  • httpie — cliente HTTP legible
  • gobuster / dirb — descubre rutas en un sitio propio o autorizado
  • Wappalyzer — tecnologías usadas en un sitio
pkg install nikto httpie

Criptografía y contraseñas

  • openssl — claves, certificados, hashes, cifrado
  • gpg — cifrado y firma de archivos
  • hashid — identifica el tipo de un hash
  • john / hashcat — auditoría de contraseñas propias
pkg install openssl-tool gnupg

Automatización y scripting

  • Python — automatización, scraping, prototipos
  • Bash scripting — automatiza comandos repetitivos
  • tmux — varias sesiones de terminal en paralelo
pkg install python tmux git

Monitoreo del sistema

  • htop — procesos y uso de CPU/RAM
  • neofetch — información del sistema
  • df -h — espacio de almacenamiento
  • termux-battery-status — estado de batería
pkg install htop neofetch termux-api

Fundamentos de forense digital

  • exiftool — metadatos de imágenes y documentos
  • binwalk — contenido embebido en binarios
  • sha256sum / md5sum — verifica integridad de archivos
  • file — identifica el tipo real de un archivo
pkg install exiftool binwalk

Hardening básico

  • Mantén Termux actualizado con pkg upgrade
  • Contraseñas fuertes para SSH (passwd)
  • Con openssh, usa llaves en vez de contraseña
  • Revisa procesos activos con htop
  • No expongas Apache a internet sin firewall/HTTPS/autenticación

Repositorios recomendados

  • termux/termux-app — repositorio oficial de Termux
  • danielmiessler/SecLists — listas de palabras para pruebas de seguridad autorizadas
  • nmap/nmap — código fuente de Nmap
  • sundowndev/PhoneInfoga — OSINT sobre números telefónicos públicos

Uso ético y legal

Estas herramientas son usadas por profesionales de seguridad, pero pueden causar daño si se usan mal. Antes de escanear o investigar algo que no es tuyo:

  • Obtén autorización por escrito cuando sea posible
  • Practica en entornos legales (laboratorios propios, plataformas CTF)
  • Conoce las leyes de tu país sobre acceso no autorizado a sistemas
