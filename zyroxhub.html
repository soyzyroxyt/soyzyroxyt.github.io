Glosario técnico

Términos comunes explicados simple.

OSINT

Open Source Intelligence: inteligencia obtenida de fuentes públicas y abiertas.

Payload

El código o dato que realmente ejecuta la acción dentro de un exploit o script.

Sandbox

Entorno aislado donde se prueba software sin afectar el sistema real.

Root

Acceso total de administrador sobre un sistema Linux/Android.
